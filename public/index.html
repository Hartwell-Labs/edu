How it works

Three rules, no fluff.

1 · It runs where you are

Python runs in WebAssembly through Pyodide, Ruby through Opal. Nothing is sent to a server, nothing you paste leaves the tab. The checker runs in your browser too.

2 · The failure is the lesson

You get the assertion, the expected value, the actual value and the line. Not a score. Hints are one at a time and they cost points, so you try the hard way first.

3 · Heavy labs get a real machine

Anything that needs a kernel, a network or a compiler runs in the lab VM you download and run locally. Same image for everyone, reproducible, no cloud bill.

Lab VM

The part that needs a real machine.

Exploitation, forensics, eBPF and anything else that cannot run in a tab ships as a downloadable virtual machine. You build it once or grab the image, run it locally, and the labs inside it check themselves.

bash lab-vm/build.sh # zbuduj obraz qcow2 lokalnie
bash lab-vm/build.sh --run # zbuduj i odpal w QEMU
