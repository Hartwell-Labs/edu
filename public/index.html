Interactive labs

Write the code. Run it. Read the failure.

Anvil is a set of labs where you run something instead of guessing. Python compiles to WebAssembly and runs in your browser — your code and the checks never touch our servers. When a check fails you get the assertion, the value you produced and the line where they disagree. Three hundred labs across cybersecurity, Python, Ruby and Rust; the first ten are free with an account.

How a lab works
01

Everything runs on your machine

Code and checks run in your browser. Only a nickname, your progress and which labs you solved travel to the server.

02

The failure is the lesson

You get the assertion, the expected value, the value you produced and the line where they disagree. Hints come one at a time and cost points.

03

Hard labs get a real machine

When a lab needs a kernel, a network or a compiler, you get an image you build or download, and labcheck verifies it with no network involved.

Lab machine

Some labs need Linux, not a browser tab

Exploits, forensics, eBPF. The lab machine is a plain image you build or download, run locally, and verify offline with labcheck. Every checker runs on the correct answer and on a deliberately wrong one — a checker that accepts a bad answer is a bug we test for.

bash lab-vm/build.sh --test # runs every lab checker locally
bash lab-vm/build.sh --run # full image under QEMU
