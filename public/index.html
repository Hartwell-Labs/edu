Write code. Run it. See what did not work.

Anvil is a set of labs where you actually run something. Python runs in your browser (WebAssembly — nothing is sent to a server), and the checker tells you which test passed, which failed, and why instead of “wrong answer”. Sixteen labs across cybersecurity, Python, Ruby and Rust. The first ten are free with a free account; the deeper paths live in the paid tier.

Three rules
01

Nothing leaves your browser

Your code and the tests run on your machine. Only a nickname, your progress and which tasks you solved travel to the server.

02

A failure is the lesson

You get the assertion, the expected value, the value you got and the line where they disagree. Hints are one at a time and cost points — try on your own first.

03

Hard labs get a real machine

Need a kernel, a network or a compiler? Download the lab machine image, run it locally, and verify offline with labcheck.

Lab machine

Some labs need Linux, not a browser tab

Exploits, forensics, eBPF — none of that can be simulated in a tab. The lab machine is a plain image you build or download, run locally, and labcheck verifies your solution with no internet involved.

bash lab-vm/build.sh --host # no QEMU: verifies everything locally
bash lab-vm/build.sh --run # full image in QEMU

The paid tier: full paths, lifetime, no subscription

The first ten labs are free and stay free. The second tier opens the six labs that go past them — sliding-window rate limiting that has to survive a real network, a scanner that stays inside its scope and its request budget, a safe bpf_probe_read_user wrapper, and a service you have to run yourself to see the leak. Lifetime means once, not monthly. Beyond that we also write labs for a team, run private groups, and build a lab machine around your stack. No price list — the scope decides the number, so we quote it in a conversation.
